# Hackathon Rules — PocketShift AI

## Originality
- All code, docs, notebooks, tests and assets are created during the event.
- No pre-built code or materials prepared prior to the competition window are
  included. The `PerformanceContextAdapter` is written fresh for this project.

## Claims discipline
- No false claim of official NFL endorsement, medical validation, injury
  prediction, or live NFL data.
- The preparation screen is a prototype decision-support bridge, not a validated
  injury-prevention or medical system.

## Secrets & data
- No secrets, credentials, or confidential material committed. `.env` is ignored.
- Respect dataset licensing: the raw CSVs are gitignored and NOT redistributed.
  The repo ships download/setup instructions instead.

## Build discipline
- Working product before optional features.
- Tests must actually run and pass before any "passing" claim.
